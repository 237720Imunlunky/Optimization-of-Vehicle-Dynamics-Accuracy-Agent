# CarSim纵向参数优化Agent交互界面

这是本项目的本地操作控制台，提供精度看板、API配置状态、参数空间、候选生成、完整优化、迭代历史和任务日志。

## API手动配置

指定文件：

`config/llm_api.local.json`

打开后手动填写：

```json
{
  "api_key": "你的API密钥",
  "base_url": "OpenAI兼容接口根地址，例如https://api.example.com/v1",
  "model": "模型名称",
  "timeout_s": 120
}
```

密钥不会返回到浏览器，不会写入Agent日志。该文件已加入本模块的`.gitignore`。

## 启动方式

在`项目实现`目录执行：

```powershell
python "Agent交互界面/server.py"
```

浏览器打开：`http://127.0.0.1:8765`

服务只监听本机地址。关闭运行该命令的终端即可停止服务。

## 界面操作

- `执行干运行`：不调用外部API，不运行CarSim，只验证下一候选和保护机制；
- `开始完整优化`：启动多轮闭环。每轮调用LLM生成候选，并依次评价本轮全部通过预检查的候选，再选出本轮最优者进入下一轮；最大轮数和连续无提升停止轮数均读取项目根目录`config.json`，页面不会另存一套默认值。每轮结果独立保存，不覆盖历史最优点；
- 如果`输出/LLM参数优化Agent/`中没有已完成的CarSim评价状态，干运行、看板和完整优化首轮会自动从`输出/正式联合基线/当前配置基线/formal_acceptance.json`冷启动；存在评价历史时则自动从最近最优状态续跑。清理优化历史不会再导致界面无法启动；
- 每次点击`开始完整优化`都是一个新的优化任务，本次任务的“连续无提升”从第1轮重新计数；上一任务的无提升次数只作为提示词经验和状态审计，不会让新任务首轮直接触发停止。
- `经验记忆`：每轮保存C1/C2/C3的参数变化、指标改善/退化和回退原因。下一轮分别生成沿最优点利用、融合已验证非胜者收益、避开失败方向探索的候选；看板会显示已累计的经验轮数；
- `打开配置文件`：使用系统默认编辑器打开`llm_api.local.json`；
- `重新检查`：重新读取本地API配置，不向外部发送请求。
- `暂停`：等待当前LLM调用或CarSim候选评价结束后，在安全边界暂停；点击“继续”恢复同一任务。
- `安全停止`：等待当前步骤结束后终止后续候选和轮次，保留已完成证据与当前最优点。

看板“当前参数变化”按当前最优点与正式基线动态比较：只有一项变化时直接显示参数和值，
多项变化时显示调整数量，鼠标悬停可查看全部参数变化。它不再固定突出某一个动力参数。

开始完整优化前，先进入“数据准入”页面生成或刷新批次。只有最新清单中每类工况的合格样本都满足
`config.json` 规定的最少标定集和验证集数量时，真实闭环才允许启动；待人工复核的数据默认不参与。

启动时的经验模式含义如下：

- `继承验证经验`：继承与当前策略指纹一致、经过 CarSim 验证且已压缩去重的历史经验；
- `全新优化`：从正式基线和空经验开始，不读取旧任务经验，也不会删除任何历史文件。

“历史空间”页面按完整任务显示占用、经验摘要校验状态、保护原因和预计可释放空间。系统默认仅生成预览，
当前最优、最近 3 次任务、未完成任务和摘要未校验任务始终受保护。实际删除需要明确输入确认文字，且不可恢复；
首次上线请保持自动清理关闭，先人工核对预览。

任务日志默认显示“过程摘要”，包括当前阶段、轮次进度、候选完成度、C1/C2/C3评分、未通过项数量、最近动作和当前最优分数。干运行结束后也会显示候选生成数量和“优化完成（干运行）”状态。
切换到“原始日志”后可查看完整的LLM/CarSim命令输出，用于排查接口或求解器错误。

优化看板区分两种指标口径：`工况平均指标`显示3类工况各4项均值，共12项；
`逐样本未通过`按每份实车样本逐项检查，当前数据策略共64次判断。失败详情会显示重复编号以及标定集/验证集分组。
当LLM返回空正文、Markdown代码块、分段正文或不完整JSON时，后端会按`config.json`自动进行格式重试，
原始日志会显示当前重试次数。每次尝试的非敏感摘要保存在对应候选目录的`llm_response_attempts.json`。
当前DeepSeek V4通过`config.json.agent.llm_thinking_mode=disabled`直接输出结构化候选，
避免模型在任务日志中输出长篇思考并因长度上限中断。

所有新输出继续分类保存到`项目实现/输出/LLM参数优化Agent/`。CarSim Runtime 读取本机
`config/runtime.local.json`，允许任意盘符，但必须使用纯英文ASCII路径。

移植到其他电脑时使用项目根目录的 `部署包/`。没有 CarSim 或授权时，本界面仍可浏览历史、执行数据准入和干运行，
但会阻止“开始完整优化”并显示缺失项。本机路径只配置在 `config/runtime.local.json`，API 密钥只配置在
`Agent交互界面/config/llm_api.local.json`。
