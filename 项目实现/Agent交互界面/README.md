# CarSim纵向参数优化Agent交互界面

这是本项目的本地操作控制台，提供精度看板、API配置状态、参数空间、候选生成、完整优化、迭代历史和任务日志。

## API手动配置

指定文件：

`config/llm_api.local.json`

打开后手动填写：

```json
{
  "api_key": "你的API密钥",
  "base_url": "OpenAI兼容接口根地址，例如https://api.example.com/v1",
  "model": "模型名称",
  "timeout_s": 120
}
```

密钥不会返回到浏览器，不会写入Agent日志。该文件已加入本模块的`.gitignore`。

## 启动方式

在`项目实现`目录执行：

```powershell
python "Agent交互界面/server.py"
```

浏览器打开：`http://127.0.0.1:8765`

服务只监听本机地址。关闭运行该命令的终端即可停止服务。

## 界面操作

- `执行干运行`：不调用外部API，不运行CarSim，只验证下一候选和保护机制；
- `开始完整优化`：启动多轮闭环。每轮调用LLM生成候选，并依次评价本轮全部通过预检查的候选，再选出本轮最优者进入下一轮；默认最多12轮，连续3轮无提升自动停止。每轮结果独立保存，不覆盖历史最优点；
- 每次点击`开始完整优化`都是一个新的优化任务，本次任务的“连续无提升”从第1轮重新计数；上一任务的无提升次数只作为提示词经验和状态审计，不会让新任务首轮直接触发停止。
- `经验记忆`：每轮保存C1/C2/C3的参数变化、指标改善/退化和回退原因。下一轮分别生成沿最优点利用、融合已验证非胜者收益、避开失败方向探索的候选；看板会显示已累计的经验轮数；
- `打开配置文件`：使用系统默认编辑器打开`llm_api.local.json`；
- `重新检查`：重新读取本地API配置，不向外部发送请求。

所有新输出继续分类保存到`项目实现/输出/LLM参数优化Agent/`，运行目录位于F盘CarSim AgentRuntime。
