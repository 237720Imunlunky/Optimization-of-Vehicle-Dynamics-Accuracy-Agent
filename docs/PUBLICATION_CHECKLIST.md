- 工况说明图片具有公开发布权；

```powershell
python scripts/check_public_release.py
```

## 已提交商业模型的历史处理

`初版参数与配置/动力系统/Run_all.par` 曾出现在初始 Git 提交中。当前工作区已经停止跟踪并保留本机副本，
但普通删除不能清除历史提交。若该文件没有公开再分发授权，仓库所有者必须在正式公开前清理历史。

截至 2026-08-27，`origin` 对应的 GitHub 仓库为公开状态，`origin/main` 的提交
`a8ee5b64a31a1262a44b741222ef4bf30c5278a6` 仍包含该文件。该项属于高风险阻塞，不能仅靠后续普通删除解决。

建议先创建完整镜像备份，再使用 `git filter-repo` 对目标路径执行历史移除，并核对所有分支和标签。
历史重写会改变提交 ID，也需要强制更新远端，不能在未通知协作者时执行。
